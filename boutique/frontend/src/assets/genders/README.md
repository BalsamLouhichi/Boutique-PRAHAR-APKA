Photos des tuiles "Achetez par profil" (page d'accueil).

Dépose ici 4 fichiers nommés exactement :

- femme.jpg (ou .jpeg / .png / .webp)
- homme.jpg
- enfant.jpg
- unisexe.jpg

Aucun code à modifier : chaque fichier remplace automatiquement la photo
produit utilisée par défaut pour ce genre. S'il manque un fichier, la tuile
retombe sur la première photo produit trouvée dans ce rayon.
