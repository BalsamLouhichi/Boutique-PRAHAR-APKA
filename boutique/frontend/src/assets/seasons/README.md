Photos des tuiles "Achetez par saison" (page d'accueil).

Dépose ici 2 fichiers nommés exactement :

- ete.jpg (ou .jpeg / .png / .webp)
- hiver.jpg

Aucun code à modifier : chaque fichier remplace automatiquement la photo
produit utilisée par défaut pour cette saison. S'il manque un fichier, la
tuile retombe sur la première photo produit trouvée pour cette saison.
